# oura-sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A command-line tool that logs in to the Oura API v2 with OAuth2 and writes a day-per-row CSV identical in layout to the retired Oura web "Trends" export.

**Architecture:** Pure functions do the work (column mapping, day assembly, CSV formatting, date-range resolution) and are unit tested with synthetic fixtures. Thin I/O layers (config files, API client, OAuth login, CLI) take their dependencies (fetch, clock, prompt, browser opener) as parameters so tests inject stubs. No runtime dependencies; Node 24 runs the TypeScript directly.

**Tech Stack:** TypeScript 5.9 (type-check only), Node 24 (type stripping, built-in fetch, `node:test`, `node:util` parseArgs), npm.

**Spec:** `docs/superpowers/specs/2026-10-07-oura-sync-design.md`

## Global Constraints

- Node `>=24`; package is `"type": "module"`; local imports use the `.ts` extension.
- Only erasable TypeScript syntax (no enums, no parameter properties, no namespaces); `tsconfig` sets `erasableSyntaxOnly: true`.
- Zero runtime dependencies. devDependencies: `typescript`, `@types/node` only.
- Nothing in the repo refers to any specific person, path on a specific machine, or health condition. Fixtures are synthetic. `*.csv` and `sample data/` are gitignored.
- The 54 CSV headers are reproduced byte for byte, including `Sleep Timin Score` and the trailing space in `Total Bedtime `.
- Config dir: `$XDG_CONFIG_HOME/oura-sync` else `~/.config/oura-sync`. `config.json` and `tokens.json` are written mode `0600`.
- Output dir precedence: `--out`, `OURA_SYNC_OUT`, `config.outDir`, cwd. Output file `<end>-oura-trends.csv`, overwritten if present.
- Default end = today (local). Default start = day after the latest `YYYY-MM-DD-oura-trends.csv` in the output dir; none and no `--start` is an error. Start after end is an error.
- Sleep columns come from the day's `long_sleep` period (longest if several). Days with no documents are omitted. Rows sorted by day ascending.
- 429: wait `Retry-After` (default 5 s), retry up to 3 times. 401: refresh once, retry; second 401 fails with "Run `oura-sync login`". Other non-2xx: fail with status and body. Nothing written on failure.
- Scopes requested: `daily heartrate`. Redirect URI `http://localhost:<port>/callback`, default port 8477.
- Commit after every task with a conventional message.

## Review Focus

Inputs the spec implies but did not call out, each pinned by a test in the owning task:

1. A numeric zero (steps 0, temperature deviation 0) must print as `0`, not blank. Task 3 `formatCell` test.
2. A sleep period whose `day` lies outside the requested range (the API can return the night before `start`) must not create a row. Task 3 `assembleDays` test.
3. A malformed date such as `2026-9-1` or `2026-02-30` must be rejected with a usage message, not silently sent to the API. Task 4 `isIsoDate` tests.
4. A refresh response that omits `refresh_token` must keep the previous refresh token rather than storing `undefined`. Task 7 `toTokens` test.
5. An output directory that does not exist yet must be created rather than crashing on write. Task 8 `runExport` test.

```ts
export class UsageError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'UsageError';
  }
}

export class AuthRequiredError extends Error {
  constructor(message = 'Authentication failed. Run `oura-sync login`.') {
    super(message);
    this.name = 'AuthRequiredError';
  }
}

export class ApiError extends Error {
  readonly status: number;
  readonly body: string;

  constructor(status: number, body: string) {
    super(`Oura API returned ${status}: ${body}`);
    this.name = 'ApiError';
    this.status = status;
    this.body = body;
  }
}
```

```ts
import { COLUMNS, type CellValue, type Column, type DayRecord } from './mapping.ts';
import type { DailyActivity, DailyReadiness, DailySleep, SleepPeriod } from './oura-types.ts';

export interface Collections {
  dailySleep: readonly DailySleep[];
  sleep: readonly SleepPeriod[];
  readiness: readonly DailyReadiness[];
  activity: readonly DailyActivity[];
}

export interface DateRange {
  start: string;
  end: string;
}

/** The night's main sleep: the long_sleep period, longest if several. Naps are ignored. */
export function selectSleepPeriod(periods: readonly SleepPeriod[]): SleepPeriod | undefined {
  let best: SleepPeriod | undefined;
  for (const p of periods) {
    if (p.type !== 'long_sleep') continue;
    if (!best || (p.total_sleep_duration ?? 0) > (best.total_sleep_duration ?? 0)) best = p;
  }
  return best;
}

/** Join the four collections by day. Days with no documents are omitted; rows are sorted ascending. */
export function assembleDays(c: Collections, range: DateRange): DayRecord[] {
  const inRange = (day: string) => day >= range.start && day <= range.end;
  const byDay = new Map<string, DayRecord>();
  const record = (day: string): DayRecord => {
    let r = byDay.get(day);
    if (!r) {
      r = { day };
      byDay.set(day, r);
    }
    return r;
  };

  for (const d of c.dailySleep) if (inRange(d.day)) record(d.day).dailySleep = d;
  for (const d of c.readiness) if (inRange(d.day)) record(d.day).readiness = d;
  for (const d of c.activity) if (inRange(d.day)) record(d.day).activity = d;

  const sleepByDay = new Map<string, SleepPeriod[]>();
  for (const p of c.sleep) {
    if (!inRange(p.day)) continue;
    const list = sleepByDay.get(p.day) ?? [];
    list.push(p);
    sleepByDay.set(p.day, list);
  }
  for (const [day, periods] of sleepByDay) {
    const chosen = selectSleepPeriod(periods);
    if (chosen) record(day).sleep = chosen;
  }

  return [...byDay.values()].sort((a, b) => a.day.localeCompare(b.day));
}

export function formatCell(v: CellValue): string {
  if (v === null || v === undefined) return '';
  const s = String(v);
  return /[",\n\r]/.test(s) ? `"${s.replaceAll('"', '""')}"` : s;
}

export function toCsv(records: readonly DayRecord[], columns: readonly Column[] = COLUMNS): string {
  const lines = [columns.map((c) => formatCell(c.header)).join(',')];
  for (const r of records) lines.push(columns.map((c) => formatCell(c.value(r))).join(','));
  return lines.join('\n') + '\n';
}
```

```ts
import { UsageError } from './errors.ts';

const ISO_DATE = /^\d{4}-\d{2}-\d{2}$/;
const EXPORT_FILE = /^(\d{4}-\d{2}-\d{2})-oura-trends\.csv$/;

export function isIsoDate(s: string): boolean {
  if (!ISO_DATE.test(s)) return false;
  const d = new Date(`${s}T00:00:00Z`);
  return !Number.isNaN(d.getTime()) && d.toISOString().slice(0, 10) === s;
}

export function todayLocal(now: Date = new Date()): string {
  const y = now.getFullYear();
  const m = String(now.getMonth() + 1).padStart(2, '0');
  const d = String(now.getDate()).padStart(2, '0');
  return `${y}-${m}-${d}`;
}

export function nextDay(date: string): string {
  const d = new Date(`${date}T00:00:00Z`);
  d.setUTCDate(d.getUTCDate() + 1);
  return d.toISOString().slice(0, 10);
}

export function latestExportDate(filenames: readonly string[]): string | null {
  let latest: string | null = null;
  for (const f of filenames) {
    const m = EXPORT_FILE.exec(f);
    if (m && (latest === null || m[1]! > latest)) latest = m[1]!;
  }
  return latest;
}

export function exportFileName(end: string): string {
  return `${end}-oura-trends.csv`;
}

export interface RangeOptions {
  start?: string;
  end?: string;
  existing: readonly string[];
  today: string;
}

export function resolveRange(opts: RangeOptions): { start: string; end: string } {
  const end = opts.end ?? opts.today;
  if (!isIsoDate(end)) throw new UsageError(`--end must be YYYY-MM-DD, got "${end}"`);

  let start = opts.start;
  if (start === undefined) {
    const latest = latestExportDate(opts.existing);
    if (latest === null) {
      throw new UsageError('No previous export found in the output directory. Pass --start YYYY-MM-DD.');
    }
    start = nextDay(latest);
  }
  if (!isIsoDate(start)) throw new UsageError(`--start must be YYYY-MM-DD, got "${start}"`);
  if (start > end) throw new UsageError(`--start ${start} is after --end ${end}`);
  return { start, end };
}
```

```ts
import { homedir } from 'node:os';
import { dirname, join, resolve } from 'node:path';

export interface Config {
  clientId: string;
  clientSecret: string;
  redirectPort: number;
  outDir?: string;
}

export interface Tokens {
  accessToken: string;
  refreshToken: string;
  /** Unix epoch milliseconds. */
  expiresAt: number;
}

export const DEFAULT_REDIRECT_PORT = 8477;
const FILE_MODE = 0o600;

export function configDir(env: NodeJS.ProcessEnv = process.env): string {
  const base = env.XDG_CONFIG_HOME ? env.XDG_CONFIG_HOME : join(homedir(), '.config');
  return join(base, 'oura-sync');
}

async function readJson<T>(path: string): Promise<T | null> {
  try {
    return JSON.parse(await readFile(path, 'utf8')) as T;
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code === 'ENOENT') return null;
    throw err;
  }
}

async function writeJson(path: string, value: unknown): Promise<void> {
  await mkdir(dirname(path), { recursive: true });
  await writeFile(path, JSON.stringify(value, null, 2) + '\n', { mode: FILE_MODE });
  // writeFile's mode only applies when the file is created; enforce it on overwrite too.
  await chmod(path, FILE_MODE);
}

export function readConfig(dir: string): Promise<Config | null> {
  return readJson<Config>(join(dir, 'config.json'));
}

export function writeConfig(dir: string, config: Config): Promise<void> {
  return writeJson(join(dir, 'config.json'), config);
}

export function readTokens(dir: string): Promise<Tokens | null> {
  return readJson<Tokens>(join(dir, 'tokens.json'));
}

export function writeTokens(dir: string, tokens: Tokens): Promise<void> {
  return writeJson(join(dir, 'tokens.json'), tokens);
}

export interface OutDirOptions {
  flag?: string;
  env: NodeJS.ProcessEnv;
  config: Config | null;
  cwd: string;
}

/** Precedence: --out flag, OURA_SYNC_OUT, config.outDir, cwd. Relative paths resolve against cwd. */
export function resolveOutDir(opts: OutDirOptions): string {
  const chosen = opts.flag ?? (opts.env.OURA_SYNC_OUT || undefined) ?? opts.config?.outDir ?? opts.cwd;
  return resolve(opts.cwd, chosen);
}
```

```ts
  body?: unknown;
  headers?: Record<string, string>;
}

export interface FetchCall {
  url: string;
  method: string;
  auth: string | undefined;
  body: string | undefined;
}

/**
 * A fetch stub driven by a route function. The route sees each call in order
 * and returns the response to send. Throws if called with no response.
 */
export function stubFetch(route: (call: FetchCall, index: number) => StubResponse | undefined) {
  const calls: FetchCall[] = [];
  const fetchFn = (async (input: string | URL | Request, init?: RequestInit) => {
    const headers = (init?.headers ?? {}) as Record<string, string>;
    const call: FetchCall = {
      url: String(input),
      method: init?.method ?? 'GET',
      auth: headers.Authorization,
      body: typeof init?.body === 'string' ? init.body : undefined,
    };
    const res = route(call, calls.length);
    calls.push(call);
    if (!res) throw new Error(`Unexpected fetch: ${call.method} ${call.url}`);
    const text = res.body === undefined ? '' : typeof res.body === 'string' ? res.body : JSON.stringify(res.body);
    return new Response(text, { status: res.status, headers: res.headers });
  }) as typeof fetch;
  return { fetchFn, calls };
}

/** Returns responses in sequence, regardless of URL. */
export function sequence(responses: StubResponse[]) {
  return stubFetch((_call, i) => responses[i]);
```

```ts
import { ApiError, AuthRequiredError } from './errors.ts';
import type { MultiDocumentResponse } from './oura-types.ts';

export const API_BASE = 'https://api.ouraring.com';
export const MAX_RATE_LIMIT_RETRIES = 3;
const DEFAULT_RETRY_AFTER_SECONDS = 5;

export interface ApiClientOptions {
  getAccessToken: () => Promise<string>;
  /** Refresh and return the new access token. Throw AuthRequiredError if that is impossible. */
  refreshAccessToken: () => Promise<string>;
  fetchFn?: typeof fetch;
  sleep?: (ms: number) => Promise<void>;
  baseUrl?: string;
}

export class OuraApi {
  readonly #getAccessToken: () => Promise<string>;
  readonly #refreshAccessToken: () => Promise<string>;
  readonly #fetchFn: typeof fetch;
  readonly #sleep: (ms: number) => Promise<void>;
  readonly #baseUrl: string;

  constructor(opts: ApiClientOptions) {
    this.#getAccessToken = opts.getAccessToken;
    this.#refreshAccessToken = opts.refreshAccessToken;
    this.#fetchFn = opts.fetchFn ?? fetch;
    this.#sleep = opts.sleep ?? ((ms) => new Promise((r) => setTimeout(r, ms)));
    this.#baseUrl = opts.baseUrl ?? API_BASE;
  }

  /** Fetch every document in a usercollection for [start, end], following pagination. */
  async fetchCollection<T>(collection: string, start: string, end: string): Promise<T[]> {
    const items: T[] = [];
    let nextToken: string | null = null;
    do {
      const url = new URL(`/v2/usercollection/${collection}`, this.#baseUrl);
      url.searchParams.set('start_date', start);
      url.searchParams.set('end_date', end);
      if (nextToken) url.searchParams.set('next_token', nextToken);
      const page: MultiDocumentResponse<T> = await this.#getJson(url);
      items.push(...page.data);
      nextToken = page.next_token;
    } while (nextToken);
    return items;
  }

  async #getJson<T>(url: URL): Promise<T> {
    let token = await this.#getAccessToken();
    let refreshed = false;
    let rateLimitRetries = 0;
    for (;;) {
      const res = await this.#fetchFn(url, { headers: { Authorization: `Bearer ${token}` } });
      if (res.ok) return (await res.json()) as T;

      if (res.status === 401) {
        if (refreshed) throw new AuthRequiredError();
        refreshed = true;
        token = await this.#refreshAccessToken();
        continue;
      }

      if (res.status === 429 && rateLimitRetries < MAX_RATE_LIMIT_RETRIES) {
        rateLimitRetries++;
        const header = Number(res.headers.get('retry-after'));
        const seconds = Number.isFinite(header) && header > 0 ? header : DEFAULT_RETRY_AFTER_SECONDS;
        await this.#sleep(seconds * 1000);
        continue;
      }

      throw new ApiError(res.status, await res.text());
    }
  }
}
```

```ts
import { createHash, randomBytes } from 'node:crypto';
import { createServer } from 'node:http';
import type { AddressInfo } from 'node:net';
import type { Config, Tokens } from './config.ts';
import { AuthRequiredError } from './errors.ts';

export const AUTHORIZE_URL = 'https://cloud.ouraring.com/oauth/authorize';
export const TOKEN_URL = 'https://api.ouraring.com/oauth/token';
export const SCOPES = 'daily heartrate';
const DEFAULT_LOGIN_TIMEOUT_MS = 5 * 60 * 1000;

export function pkceChallenge(verifier: string): string {
  return createHash('sha256').update(verifier).digest('base64url');
}

export function newVerifier(): string {
  return randomBytes(32).toString('base64url');
}

export function redirectUri(port: number): string {
  return `http://localhost:${port}/callback`;
}

export function authorizeUrl(p: {
  clientId: string;
  redirectUri: string;
  state: string;
  challenge: string;
  scope?: string;
}): string {
  const url = new URL(AUTHORIZE_URL);
  url.searchParams.set('response_type', 'code');
  url.searchParams.set('client_id', p.clientId);
  url.searchParams.set('redirect_uri', p.redirectUri);
  url.searchParams.set('scope', p.scope ?? SCOPES);
  url.searchParams.set('state', p.state);
  url.searchParams.set('code_challenge', p.challenge);
  url.searchParams.set('code_challenge_method', 'S256');
  return url.toString();
}

export interface TokenResponse {
  access_token: string;
  token_type: string;
  expires_in: number;
  refresh_token?: string;
}

export function toTokens(r: TokenResponse, previousRefresh: string | undefined, now: number): Tokens {
  const refreshToken = r.refresh_token ?? previousRefresh;
  if (!refreshToken) throw new Error('Token response contained no refresh_token');
  return { accessToken: r.access_token, refreshToken, expiresAt: now + r.expires_in * 1000 };
}

interface TokenRequestOptions {
  fetchFn?: typeof fetch;
  now?: number;
  tokenUrl?: string;
}

async function postToken(params: Record<string, string>, opts: TokenRequestOptions): Promise<TokenResponse> {
  const fetchFn = opts.fetchFn ?? fetch;
  const res = await fetchFn(opts.tokenUrl ?? TOKEN_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams(params).toString(),
  });
  if (!res.ok) {
    throw new AuthRequiredError(`Oura token request failed (${res.status}): ${await res.text()}. Run \`oura-sync login\`.`);
  }
  return (await res.json()) as TokenResponse;
}

export async function exchangeCode(
  opts: { config: Config; code: string; verifier: string } & TokenRequestOptions,
): Promise<Tokens> {
  const r = await postToken(
    {
      grant_type: 'authorization_code',
      code: opts.code,
      code_verifier: opts.verifier,
      client_id: opts.config.clientId,
      client_secret: opts.config.clientSecret,
      redirect_uri: redirectUri(opts.config.redirectPort),
    },
    opts,
  );
  return toTokens(r, undefined, opts.now ?? Date.now());
}

export async function refreshTokens(opts: { config: Config; tokens: Tokens } & TokenRequestOptions): Promise<Tokens> {
  const r = await postToken(
    {
      grant_type: 'refresh_token',
      refresh_token: opts.tokens.refreshToken,
      client_id: opts.config.clientId,
      client_secret: opts.config.clientSecret,
    },
    opts,
  );
  return toTokens(r, opts.tokens.refreshToken, opts.now ?? Date.now());
}

export interface CallbackOptions {
  port: number;
  state: string;
  timeoutMs: number;
  /** Called once the server is listening, with the actual port (useful when port is 0). */
  onListening: (port: number) => void | Promise<void>;
}

/** Run a one-shot HTTP server that waits for Oura's redirect and resolves with the authorization code. */
export function waitForCallback(opts: CallbackOptions): Promise<string> {
  return new Promise((resolve, reject) => {
    const server = createServer((req, res) => {
      const url = new URL(req.url ?? '/', 'http://localhost');
      if (url.pathname !== '/callback') {
        res.writeHead(404).end();
        return;
      }
      const finish = (status: number, text: string, outcome: () => void) => {
        res.writeHead(status, { 'Content-Type': 'text/plain; charset=utf-8' }).end(text);
        clearTimeout(timer);
        server.close();
        outcome();
      };
      const error = url.searchParams.get('error');
      const code = url.searchParams.get('code');
      const state = url.searchParams.get('state');
      if (error) return finish(400, `Oura returned an error: ${error}`, () => reject(new Error(`Authorization failed: ${error}`)));
      if (state !== opts.state) return finish(400, 'State mismatch. Try logging in again.', () => reject(new Error('OAuth state mismatch')));
      if (!code) return finish(400, 'Missing code.', () => reject(new Error('Callback had no code')));
      finish(200, 'Logged in to Oura. You can close this tab.', () => resolve(code));
    });
    const timer = setTimeout(() => {
      server.close();
      reject(new Error('Timed out waiting for the browser callback'));
    }, opts.timeoutMs);
    server.on('error', (err) => {
      clearTimeout(timer);
      reject(err);
    });
    server.listen(opts.port, '127.0.0.1', () => {
      const port = (server.address() as AddressInfo).port;
      Promise.resolve(opts.onListening(port)).catch((err) => {
        clearTimeout(timer);
        server.close();
        reject(err);
      });
    });
  });
}

export interface LoginOptions {
  config: Config;
  fetchFn?: typeof fetch;
  openBrowser?: (url: string) => Promise<void>;
  log?: (message: string) => void;
  timeoutMs?: number;
}

/** Full authorization-code + PKCE flow. Resolves with fresh tokens; the caller stores them. */
export async function login(opts: LoginOptions): Promise<Tokens> {
  const log = opts.log ?? (() => {});
  const verifier = newVerifier();
  const state = randomBytes(16).toString('base64url');
  const code = await waitForCallback({
    port: opts.config.redirectPort,
    state,
    timeoutMs: opts.timeoutMs ?? DEFAULT_LOGIN_TIMEOUT_MS,
    onListening: async (port) => {
      const url = authorizeUrl({
        clientId: opts.config.clientId,
        redirectUri: redirectUri(port),
        state,
        challenge: pkceChallenge(verifier),
      });
      log(`Opening your browser to authorize oura-sync. If it does not open, visit:\n${url}`);
      if (opts.openBrowser) {
        try {
          await opts.openBrowser(url);
        } catch {
          // The URL was printed; the user can open it by hand.
        }
      }
    },
  });
  return exchangeCode({ config: opts.config, code, verifier, fetchFn: opts.fetchFn });
}
```

Note: `exchangeCode` builds the redirect URI from `config.redirectPort`. With port 0 in tests the redirect URI in the token request will say port 0, which is fine for the stub; in real use the configured port is a fixed number, so the authorize and token requests agree.

```ts
import { execFile } from 'node:child_process';
import { mkdir, readdir, writeFile } from 'node:fs/promises';
import { platform } from 'node:os';
import { join } from 'node:path';
import { createInterface } from 'node:readline/promises';
import { parseArgs } from 'node:util';
import { OuraApi } from './api.ts';
import { login, refreshTokens } from './auth.ts';
import {
  configDir as defaultConfigDir,
  DEFAULT_REDIRECT_PORT,
  readConfig,
  readTokens,
  resolveOutDir,
  writeConfig,
  writeTokens,
  type Config,
  type Tokens,
} from './config.ts';
import { assembleDays, toCsv } from './csv.ts';
import { exportFileName, resolveRange, todayLocal } from './dates.ts';
import { ApiError, AuthRequiredError, UsageError } from './errors.ts';
import type { DailyActivity, DailyReadiness, DailySleep, SleepPeriod } from './oura-types.ts';

const REFRESH_MARGIN_MS = 60_000;

export const USAGE = `Usage:
  oura-sync login                       Authorize with Oura (one-time app setup, then browser login)
  oura-sync export [options]            Write <end>-oura-trends.csv (default command)

Options:
  --start YYYY-MM-DD   First day to export (default: day after the latest export in the output dir)
  --end YYYY-MM-DD     Last day to export (default: today)
  --out DIR            Output directory (default: $OURA_SYNC_OUT, then config outDir, then cwd)
  -h, --help           Show this help`;

export interface ExportArgs {
  start?: string;
  end?: string;
  out?: string;
}

export interface ExportDeps {
  configDir: string;
  env: NodeJS.ProcessEnv;
  cwd: string;
  today: string;
  fetchFn?: typeof fetch;
  log: (message: string) => void;
}

export async function runExport(args: ExportArgs, deps: ExportDeps): Promise<string> {
  const config = await readConfig(deps.configDir);
  if (!config) throw new AuthRequiredError('No configuration found. Run `oura-sync login` first.');
  const stored = await readTokens(deps.configDir);
  if (!stored) throw new AuthRequiredError('Not logged in. Run `oura-sync login`.');
  let tokens: Tokens = stored;

  const outDir = resolveOutDir({ flag: args.out, env: deps.env, config, cwd: deps.cwd });
  await mkdir(outDir, { recursive: true });
  const existing = await readdir(outDir);
  const range = resolveRange({ start: args.start, end: args.end, existing, today: deps.today });

  const refresh = async (): Promise<string> => {
    tokens = await refreshTokens({ config, tokens, fetchFn: deps.fetchFn });
    await writeTokens(deps.configDir, tokens);
    return tokens.accessToken;
  };
  const api = new OuraApi({
    fetchFn: deps.fetchFn,
    getAccessToken: async () => (tokens.expiresAt - Date.now() < REFRESH_MARGIN_MS ? refresh() : tokens.accessToken),
    refreshAccessToken: refresh,
  });

  // Sequential on purpose: a concurrent 401 would trigger overlapping refreshes.
  const dailySleep = await api.fetchCollection<DailySleep>('daily_sleep', range.start, range.end);
  const sleep = await api.fetchCollection<SleepPeriod>('sleep', range.start, range.end);
  const readiness = await api.fetchCollection<DailyReadiness>('daily_readiness', range.start, range.end);
  const activity = await api.fetchCollection<DailyActivity>('daily_activity', range.start, range.end);

  const records = assembleDays({ dailySleep, sleep, readiness, activity }, range);
  const path = join(outDir, exportFileName(range.end));
  await writeFile(path, toCsv(records), 'utf8');
  deps.log(`Wrote ${records.length} row${records.length === 1 ? '' : 's'} (${range.start} to ${range.end}) to ${path}`);
  return path;
}

export interface LoginDeps {
  configDir: string;
  prompt: (question: string) => Promise<string>;
  log: (message: string) => void;
  fetchFn?: typeof fetch;
  openBrowser?: (url: string) => Promise<void>;
  timeoutMs?: number;
  /** Port stored in a newly created config. Defaults to DEFAULT_REDIRECT_PORT. */
  redirectPort?: number;
}

export async function runLogin(deps: LoginDeps): Promise<void> {
  let config: Config | null = await readConfig(deps.configDir);
  if (!config) {
    deps.log('No Oura app configured yet. Create one at https://cloud.ouraring.com/oauth/applications');
    const port = deps.redirectPort ?? DEFAULT_REDIRECT_PORT;
    deps.log(`with redirect URI http://localhost:${port}/callback, then enter its credentials.`);
    const clientId = (await deps.prompt('Client ID: ')).trim();
    const clientSecret = (await deps.prompt('Client secret: ')).trim();
    if (!clientId || !clientSecret) throw new UsageError('Client ID and client secret are both required.');
    config = { clientId, clientSecret, redirectPort: port };
    await writeConfig(deps.configDir, config);
    deps.log(`Saved ${join(deps.configDir, 'config.json')}`);
  }
  const tokens = await login({
    config,
    fetchFn: deps.fetchFn,
    openBrowser: deps.openBrowser,
    log: deps.log,
    timeoutMs: deps.timeoutMs,
  });
  await writeTokens(deps.configDir, tokens);
  deps.log(`Logged in. Tokens saved to ${join(deps.configDir, 'tokens.json')}`);
}

function openBrowser(url: string): Promise<void> {
  const [cmd, args] =
    platform() === 'darwin' ? ['open', [url]] : platform() === 'win32' ? ['cmd', ['/c', 'start', '', url]] : ['xdg-open', [url]];
  return new Promise((resolve, reject) => {
    execFile(cmd, args, (err) => (err ? reject(err) : resolve()));
  });
}

async function promptLine(question: string): Promise<string> {
  const rl = createInterface({ input: process.stdin, output: process.stdout });
  try {
    return await rl.question(question);
  } finally {
    rl.close();
  }
}

export async function main(argv: string[]): Promise<number> {
  let values: { start?: string; end?: string; out?: string; help?: boolean };
  let positionals: string[];
  try {
    ({ values, positionals } = parseArgs({ args: argv, options: OPTIONS, allowPositionals: true }));
  } catch (err) {
    console.error(`${(err as Error).message}\n\n${USAGE}`);
    return 1;
  }
  if (values.help) {
    console.log(USAGE);
    return 0;
  }
  const command = positionals[0] ?? 'export';
  const dir = defaultConfigDir();
  const log = (m: string) => console.log(m);
  try {
    if (command === 'login') {
      await runLogin({ configDir: dir, prompt: promptLine, log, openBrowser });
    } else if (command === 'export') {
      await runExport(
        { start: values.start, end: values.end, out: values.out },
        { configDir: dir, env: process.env, cwd: process.cwd(), today: todayLocal(), log },
      );
    } else {
      console.error(`Unknown command "${command}"\n\n${USAGE}`);
      return 2;
    }
    return 0;
  } catch (err) {
    if (err instanceof UsageError || err instanceof AuthRequiredError || err instanceof ApiError) {
      console.error(err.message);
      return 1;
    }
    throw err;
  }
}

const OPTIONS = {
  start: { type: 'string' },
  end: { type: 'string' },
  out: { type: 'string' },
  help: { type: 'boolean', short: 'h' },
} as const;
```

````markdown
# oura-sync

Export your Oura daily trends to CSV, in the same layout as the web export
Oura retired in 2026. One row per day, 54 columns, identical headers, so
spreadsheets and scripts built on the old export keep working.

Requires Node 24 or newer. No runtime dependencies.

## One-time setup

Oura no longer issues personal access tokens, so you register your own
API application and the tool logs in through it.

1. Go to <https://cloud.ouraring.com/oauth/applications> and create an application.
2. Set the redirect URI to `http://localhost:8477/callback`.
3. Note the client ID and client secret.
4. Install and log in:

   ```sh
   git clone https://github.com/<you>/oura-sync.git
   cd oura-sync
   npm install
   npm link            # puts `oura-sync` on your PATH; or run ./bin/oura-sync.ts directly
   oura-sync login
   ```

   `login` asks for the client ID and secret the first time, then opens
   your browser to approve access. Credentials and tokens are stored in
   `~/.config/oura-sync/` (or `$XDG_CONFIG_HOME/oura-sync/`) with mode 0600.

Oura's refresh tokens expire after 30 days without use. If an export says
"Run `oura-sync login`", log in again; your configuration is kept.

## Exporting

```sh
oura-sync export --start 2026-01-01 --end 2026-01-31 --out ~/oura-exports
```

Writes `~/oura-exports/2026-01-31-oura-trends.csv`.

Defaults:

- `--end` is today. The old export included the export day, so this does too.
  Today's activity figures are partial.
- `--start` is the day after the newest `YYYY-MM-DD-oura-trends.csv` already
  in the output directory, so repeated runs tile without gaps. The first run
  needs an explicit `--start`.
- The output directory is, in order: `--out`, the `OURA_SYNC_OUT` environment
  variable, `outDir` in `config.json`, or the current directory.

Re-running with the same end date overwrites that day's file.

## Columns

All 54 headers of the old export are reproduced exactly, including Oura's
own quirks ("Sleep Timin Score", trailing space in "Total Bedtime ").
Sources:

| Group | Columns | API collection |
|---|---|---|
| Sleep durations, HR, HRV, breathing, bedtimes | Total Sleep Duration, Average Resting Heart Rate, Lowest Resting Heart Rate, Average HRV, Respiratory Rate, Bedtime Start/End, Total Bedtime, Awake Time, Sleep Latency, REM/Deep/Light Sleep Duration, Sleep Efficiency, Restless Sleep | `sleep` (the day's `long_sleep` period; naps are ignored) |
| Sleep scores | Sleep Score, Total Sleep Score, REM/Deep Sleep Score, Sleep Efficiency Score, Sleep Latency Score, Sleep Timin Score, Restfulness Score | `daily_sleep` |
| Readiness | Readiness Score, Temperature Deviation, Temperature Trend Deviation, Temperature Score, Previous Night Score, Sleep Balance Score, Previous Day Activity Score, Activity Balance Score, Resting Heart Rate Score, HRV Balance Score, Recovery Index Score | `daily_readiness` |
| Activity | Activity Burn, Total Burn, Steps, Equivalent Walking Distance, Low/Medium/High Activity Time, Rest Time, Inactive Time, Non-wear Time, Long Periods of Inactivity, Average MET, Activity Score, Stay Active Score, Move Every Hour Score, Meet Daily Targets Score, Training Frequency Score, Training Volume Score | `daily_activity` |

Known differences from the old export:

- **Sleep Timing** is always blank. The API does not expose the raw value.
- **Average Resting Heart Rate** and **Lowest Resting Heart Rate** come from
  the API's 30-second samples; the app shows 5-minute aggregates. Expect
  sub-bpm differences.
- Rows are sorted by date. The old export sometimes appended out-of-order
  days at the end.
- Days with no data at all are omitted. Days with partial data (for example
  activity but no sleep) keep their row with blanks.
````
